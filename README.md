# SAVE POINT

A retro LCD clock, calendar and weather widget for Android, styled like a handheld game console
from the 1980s and 1990s.

This page is the public home of the project. The app's source code is not published here.

## Contact

To reach the maintainer — including about SAVE POINT's use of a weather API — please
[open an issue](https://github.com/Phant0m-Snak3/SavePoint/issues).

## Weather data

SAVE POINT requests forecasts from the
[MET Norway Locationforecast API](https://api.met.no/weatherapi/locationforecast/2.0/documentation)
and identifies itself with the User-Agent `SAVEPOINT/<version> (https://github.com/Phant0m-Snak3/SavePoint)`.
